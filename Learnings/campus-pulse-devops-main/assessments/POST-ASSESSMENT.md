# Post-assessment (15 questions)

1. Which command finds listening TCP ports? A `ss -ltn` B `pwd` C `chmod` D `git log`
2. What does `>` do? A append B overwrite redirected output C pipe D compare
3. Least-privilege mode for an owner-only secret is: A 777 B 755 C 644 D 600
4. After changing an environment variable, why restart the app? A running processes inherit an environment at start B Git requires it C DNS caches source code D chmod resets it
5. Best first response to “port already in use”? A reboot B inspect with `ss -ltnp` C delete repository D use sudo randomly
6. Why use a feature branch? A isolate reviewed work B encrypt commits C run containers D avoid tests
7. A useful automated test is: A nondeterministic B independent and checks observable behavior C always skipped D secret
8. Why copy requirements before source in a Dockerfile? A cache dependencies when source changes B expose a port C add root D create DNS
9. Why run as non-root? A smaller logs B reduce impact of compromise C faster Python D enable YAML
10. A workflow does not appear in Actions. Check first: A monitor brightness B file path/event and whether pushed C Docker memory D chmod 777
11. A job exits on a failing test because: A non-zero exit status signals failure B JSON is invalid C port is open D branch is protected
12. Why gate deployment with `/health`? A prove Git history B prevent an unhealthy release from remaining live C hide logs D store secrets
13. Rollback means: A delete all images B restore a known-good release C rerun same broken command D force-push
14. Match telemetry: A logs=events, metrics=numbers over time, traces=request path B all identical C metrics=source code D traces=passwords
15. A committed token is discovered. First security action? A rename file B rotate/revoke token C encode it D add comment

Then complete one practical checkpoint selected by the instructor and explain its evidence aloud.
